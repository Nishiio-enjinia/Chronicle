# Guide de Contribution

Merci de votre intérêt pour contribuer à Chronicle ! 🎉

## Comment contribuer

1. **Fork** le projet
2. Créez une **branche** pour votre fonctionnalité (`git checkout -b feature/AmazingFeature`)
3. **Commitez** vos changements (`git commit -m 'Add some AmazingFeature'`)
4. **Push** vers la branche (`git push origin feature/AmazingFeature`)
5. Ouvrez une **Pull Request**

## Standards de code

### Backend (Node.js)

- Utilisez ES6+ (modules ES)
- Suivez les conventions de nommage camelCase
- Ajoutez des commentaires pour les fonctions complexes
- Validez toutes les entrées utilisateur

### Frontend (Vue 3)

- Utilisez la Composition API
- Suivez les conventions Vue 3
- Utilisez des noms de composants en PascalCase
- Maintenez la cohérence du style

## Tests

Avant de soumettre une PR, assurez-vous que :

- [ ] Le code fonctionne localement
- [ ] Les tests passent (si disponibles)
- [ ] La documentation est à jour
- [ ] Le code respecte les standards du projet

## Questions ?

N'hésitez pas à ouvrir une issue pour toute question !
