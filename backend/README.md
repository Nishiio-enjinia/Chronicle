# Chronicle Backend

API REST pour la gestion des changelogs et événements.

## Installation

```bash
npm install
```

## Configuration

Copiez `.env.template` vers `.env` et configurez vos variables d'environnement.

## Démarrage

```bash
# Développement
npm run dev

# Production
npm start
```
